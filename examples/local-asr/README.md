# 本地 ASR 服务示例（OpenAI 兼容）

ComeCut 的「ASR 语音转文本」面板支持**把识别交给一个外部服务**：在「模型和插件 → API 管理」里添加一个 **ASR-语音识别** 类型的服务商，前端就会直接向它的 `baseUrl` 发 HTTP 请求。

这个目录提供一个**零依赖的 mock 服务**（`server.mjs`，返回固定三条假字幕），用来：

- 复现 / 联调「ASR 服务商」这条链路；
- 作为自己接入本地或自建 ASR（whisper.cpp、SenseVoice、faster-whisper、FunASR…）时的骨架；
- 做回归测试（不依赖任何模型或网络）。

## 快速试一下

```bash
node server.mjs          # 监听 127.0.0.1:8799
```

然后在 ComeCut 里：

1. 「模型和插件 → API 管理 → 新增 API 服务」
2. 服务类型选 **ASR-语音识别**，接口地址填 `http://127.0.0.1:8799/v1`，模型名填 `mock-asr`
3. 保存后，右键时间线上的**音频剪辑** →「语音识别」
   （视频剪辑需先右键「分离音频」——面板是对音频剪辑工作的）
4. 面板里保持「标准时间字幕（SRT）」→ 点「执行语音识别」
5. 结果里应出现这三条：

```
00:00:00.000 --> 00:00:02.400
这是一段本地语音识别的测试字幕。

00:00:02.600 --> 00:00:05.200
识别完全在本机完成，不联网。

00:00:05.400 --> 00:00:08.000
看到这三行，说明服务商配置正确。
```

## 接口契约（v0.2.3 桌面版实测）

| 项 | 行为 |
|---|---|
| baseUrl 规范化 | 去掉尾部 `/`；若不以 `/v1` 结尾则自动补 `/v1` |
| 纯文本模式 | `POST {base}/v1/audio/transcriptions` |
| 时间戳模式（面板默认「标准时间字幕（SRT）」） | `POST {base}/v1/audio/transcriptions/details` |
| 请求体 | `multipart/form-data`；表单字段 `model`、`language`；文件字段固定 **`file`**（文件名 `clip.wav`，内容为 **16 kHz 单声道 WAV**，由前端 WebAudio 重采样后上传，服务端无需解视频） |
| 时间戳响应 | `{"text":"…","sample_rate":16000,"segments":[{"text":"…","start_sample":0,"end_sample":38400}]}`。**时间单位是采样点（sample），不是秒**；`sample_rate` 必须 > 0，否则面板会认为"没有可用时间戳"并退化为纯文本 |
| 纯文本响应 | `{"text":"…"}` |
| `GET /v1/models` | `{"data":[{"id":"…","task":"asr"}]}`。带 `task` 时菜单项才会归类为语音识别；**模型 id 里不要出现 `align`**，否则会额外触发 `/v1/audio/alignments` |
| 鉴权 | 配了 apiKey 时带 `Authorization: Bearer <key>`；`isLocal` 的服务商允许 apiKey 为空 |

## 关于 CORS

桌面版的请求由 Rust 侧发出，不受浏览器 CORS 限制；示例里仍加了宽松的 CORS 头，方便你在**网页版 / Canary 版**里用同一个服务做调试。若只面向桌面版，可以去掉。
